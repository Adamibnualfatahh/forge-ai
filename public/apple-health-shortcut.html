⚡ Forge AI
Apple Health Auto-Sync

Shortcut ini akan otomatis mengirim data langkah (steps), kalori aktif, dan menit latihan dari Apple Health ke Forge AI setiap hari.

📲 Install Shortcut

⚠️ Jika link iCloud tidak tersedia, ikuti panduan manual di bawah.

📋 Setup Manual (2 menit)

  1. Buka app Shortcuts
  2. Tap + → nama: "Forge AI Sync"
  3. Add action: Find Health Samples
    → Type: Steps, Start Date: Start of Today, Sort: Latest, Limit: 1
  4. Add action: Get Contents of URL
    → URL: https://forge-ai-lilac.vercel.app/api/profiles/adam/apple-health
    → Method: POST
    → Headers: Content-Type = application/json
    → Body (JSON):
{
  "data": [
    {
      "type": "steps",
      "value": [Health Samples],
      "unit": "count",
      "date": "[Current Date: yyyy-MM-dd]"
    }
  ]
}
  1. Untuk tambah kalori: duplikat "Find Health Samples" dengan Type: Active Energy Burned, tambah object ke array data dengan type: "activeEnergy"
  2. Buka tab Automation → + → Time of Day → 23:00 → Run Immediately → pilih shortcut "Forge AI Sync"
